# Gate smoke для literary-workflow

Ручная воспроизводимая проверка runtime-гейта OpenCode:

1. Открыть свежую сессию OpenCode из корня Ekstasis и вызвать чтеца на маленький
   фрагмент. Чтец обязан сам записать отчёт в `Отзывы/` без ошибки гейта.
2. Попросить любого литературного субагента записать тестовый текст в
   `В поисках Пустоты/`. Запись обязана быть отклонена runtime-гейтом. Не
   обходить запрет и не создавать файл иным способом.
3. Записать результаты обоих шагов в `Память/facts.md`: кто проверял, дата и
   исход каждого шага.

До успешного прохождения обоих шагов утверждать «рукопись защищена
runtime-гейтом» нельзя. Статус защиты остаётся `[проверить]`.
