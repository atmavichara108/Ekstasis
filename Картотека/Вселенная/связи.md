# Связи

Нелинейный граф отношений между частями — не таймлайн. Стабильные ID узлов:
`V-001…`. Допустимые типы рёбер: `резонанс образа`, `непрерывность состояния
«я»`, `топологическое соседство`, `эхо мотива`, `прямая отсылка`. У каждого
ребра обязательны цитата, файл, номер строки и степень уверенности. Без прямого
утверждения текста «до/после» порядок не устанавливается.
