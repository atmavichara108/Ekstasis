# Отзывы

Здесь хранятся полные отчёты чтений и критик — по одному файлу на сеанс.
Каноническое имя: `Отзывы/<YYYY-MM-DD> — чтение|критика — <часть>.md`;
коллизии получают ` (2)`, ` (3)` и т. д. Путь выдаёт
`node tools/literary/report-path.mjs`. Субагент пишет полный отчёт сразу в этот
файл; куратор возвращает автору только путь и краткий абстракт. Отчёты не являются
правками рукописи.
