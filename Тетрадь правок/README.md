# Тетрадь правок

Сюда корректор записывает предложения в машинно-парсимом формате:

```markdown
- [ ] **1.** тип: норма
  - файл: В поисках Пустоты/Имя части.md
  - строка: 42
  - цитата: «точная цитата с контекстом»
  - предложение: «точная замена»
  - причина: краткое правило или объяснение
```

Типы: `норма`, `сомнение`, `возможно намеренное`. Только автор меняет `[ ]` на
`[x]`; `/apply` вызывает `node tools/literary/corrections.mjs checked <файл>` и
применяет исключительно отмеченные пункты после показа точного diff и отдельного
подтверждения.
