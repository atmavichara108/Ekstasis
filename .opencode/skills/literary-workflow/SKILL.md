# Литературный workflow

Используй этот скилл при сохранении отчёта чтеца или критика, применении
отмеченных правок из `Тетрадь правок/` и получении канонического имени отчёта.

## Отчёты

Сначала получи имя:

```sh
node tools/literary/report-path.mjs --kind reading --selector "В поисках Пустоты/В поисках Нетленного.md"
node tools/literary/report-path.mjs --kind critique --selector "В поисках Пустоты/Красная планета.md"
```

Передай субагенту готовый путь. Субагент сам пишет полный отчёт в этот файл и
возвращает куратору только путь и абстракт на 2–3 строки. Куратор не получает,
не пересказывает, не сокращает и не перезаписывает полный текст; читать его
можно только по конкретной просьбе автора.

Саммаризация запрещена: инцидент 2026-09-25 показал, что она вызывает второй
дорогой прогон модели и теряет нюансы.

## Применение правок

Не разбирай Markdown глазами:

```sh
node tools/literary/corrections.mjs checked "Тетрадь правок/2026-09-25 — правки.md"
node tools/literary/corrections.mjs list "Тетрадь правок/2026-09-25 — правки.md"
```

Покажи автору точный diff только отмеченных пунктов и запроси отдельное
подтверждение. Неотмеченное не применяется: молчание = отказ.

Скилл не даёт права записи в `В поисках Пустоты/**`; применение к рукописи
возможно только после отдельного осознанного открытия автором точного scope.
