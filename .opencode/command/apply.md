Проведи `/применить` для файла тетради: `$ARGUMENTS`.

Прочитай только указанный файл через `node tools/literary/corrections.mjs checked
<файл>`. Ручной разбор markdown запрещён. Отбери исключительно пункты с `[x]`;
`[ ]` и неоднозначные отметки игнорируй. По structured JSON составь точный diff
без побочных изменений и покажи автору. До отдельного явного подтверждения
ничего не записывай.
Runtime-deny на `В поисках Пустоты/**` не обходи: если diff подтверждён, сообщи,
что для его буквального применения координатор должен отдельно открыть запись
ровно в согласованном scope. Молчание — отказ.
