Проведи `/применить` для файла тетради: `$ARGUMENTS`.

Прочитай только указанный файл. Отбери исключительно пункты с `[x]`; `[ ]` и
неоднозначные отметки игнорируй. Составь точный diff без побочных изменений и
покажи автору. До отдельного явного подтверждения ничего не записывай.
Runtime-deny на `В поисках Пустоты/**` не обходи: если diff подтверждён, сообщи,
что для его буквального применения координатор должен отдельно открыть запись
ровно в согласованном scope. Молчание — отказ.
