Проведи `/правки` для селектора: `$ARGUMENTS`.

Это явный вызов агента `corrector`; автоматически корректора не вызывай.
Проверь однозначность селектора. Потребуй для каждого пункта чекбокс `[ ]`,
цитату с контекстом, файл и строку, предложение, причину и один из трёх типов.
Результат сохрани отдельным датированным файлом в `Тетрадь правок/`. Рукопись
не изменяй.
